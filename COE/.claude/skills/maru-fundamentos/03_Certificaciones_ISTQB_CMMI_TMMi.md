## CMMI — Capability Maturity Model Integration

**Definición**: nivel de madurez de procesos de una organización.

| Nivel | Nombre | Definición resumida |
|---|---|---|
| 1 | Initial | Procesos improvisados, éxito por individuos heroicos |
| 2 | Managed | Procesos planificados y medidos a nivel de proyecto |
| 3 | Defined | Procesos organizacionales documentados y estándar |
| 4 | Quantitatively Managed | Procesos medidos y controlados estadísticamente |
| 5 | Optimizing | Proceso de mejora continua basado en datos |

**Área de práctica relevante para QA**: `PP` (Project Planning), `PM` (Project Monitoring & Control), `QPM` (Quality and Process Management), `DCM` (Data and Information Domain — incluye Configuration Management), `MC` (Measurement and Analysis).

**Auditoría**: el nivel se evalúa por presencia de evidencia institucional (prácticas existenciales y de capacidad en toda la organización), no por documentos aislados.

## TMMi — Test Maturity Model Integration

**Definición**: madurez específica de la función de pruebas.

| Nivel | Nombre |
|---|---|
| 1 | Initial |
| 2 | Level 1 — Detección de problemas |
| 3 | Level 2 — Control de proceso |
| 4 | Level 3 — Measuración y control |
| 5 | Level 4 — Optimización y mejora |

**Áreas de práctica TMMi**: Testing & QA (TPM), Test Planning & Control (CTP), Test Analysis & Design (CTD), Test Implementation & Execution (CTM), Test Monitoring & Control (CTM/COM), Test Environment & Test Tooling (CTET), Defect Management (CDM), Test Process Improvement (CTP), Test People & Skills (CTPS), Test Outsourcing (CTO).

**Uso en gobernanza**: TMMi se usa para evaluar la madurez **específica de testing** cuando CMMI cubre procesos más amplios.

## Reglas de uso (Maru)

- No afirmar nivel de madurez sin evidencia de auditoría institucional.
- Distinguir CMMI (procesos organizacionales) de TMMi (función de testing).
- Certificaciones recommendations deben verificarse con el Member Board o proveedor oficial (fechas cambian).
- Fuente oficial: `istqb.org`, `cmmiinstitute.com`, `tmmi.org`.
