# ISO 9001 e ISO 27001 (Nivel 3)

## ISO 9001:2015 — Sistemas de gestión de calidad

### Estructura (alineada con HLS)

| Cláusula | Nombre | Relación con QA |
|---|---|---|
| 4 | Contexto de la organización | Entender alcance y partes interesadas |
| 5 | Liderazgo | Compromiso de la dirección con la calidad |
| 6 | **Planificación** | Riesgos, objetivos de calidad, cambios |
| 7 | **Soporte** | Recursos, competencias, comunicación, información documentada |
| 8 | **Operación** | Planificación y control operacional, requisitos del producto, proveedores |
| 9 | **Evaluación del desempeño** | Medición, auditoría interna, revisión por dirección |
| 10 | **Mejora** | No conformidades, acciones correctivas, mejora continua |

### Los 7 principios de gestión de calidad
1. Enfoque en el cliente
2. Liderazgo
3. Implicación del personal
4. Enfoque en procesos
5. Mejora
6. Toma de decisiones basada en evidencia
7. Gestión de relaciones

### Qué aporta a gobernanza QA
- **Auditoría interna y revisión por dirección** = el proceso de auditoría de Maru.
- **Riesgos y oportunidades** (cláusula 6.1) = registro de riesgos de calidad.
- **No conformidades y acción correctiva** (cláusula 10.2) = estructura CAPA.
- **Información documentada** (cláusula 7.5) = evidencia de calidad.

### Anexo A — Controles de control (93 controles agrupados en 4 temas)

| Tema | Controles relevantes para QA |
|---|---|
| **Organizacionales** (37) | Policies, roles, inventory, information classification |
| **People** (8) | Onboarding, awareness training, offboarding |
| **Physical** (14) | Secure areas, equipment |
| **Technological** (34) | Access control, cryptography, logging, **secure development (8.25-8.29)**, vulnerability management |

### Integración con testing de seguridad
- ISO/IEC 27001 **organizacional** → qué debe protegerse.
- OWASP ASVS / Top 10 → **cómo verificar** en código y APIs.
- ISO/IEC 25010 §3.6 Security → **característica de calidad** a medir.

### Triple enlace (clave para auditoría)
```
ISO/IEC 27001  →  requisito de seguridad de la organización
OWASP          →  prueba de seguridad verificable (ASVS / Top 10)
ISO/IEC 25010  →  característica §3.6 Security del producto y sus métricas
```
