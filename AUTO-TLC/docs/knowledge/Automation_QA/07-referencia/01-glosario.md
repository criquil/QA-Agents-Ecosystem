## Términos de Automatización

| Término | Definición |
|---------|------------|
| **Assertion** | Verificación que un resultado es correcto |
| **CI/CD** | Integración Continua / Entrega Continua |
| **Coverage** | Porcentaje de código probado |
| **E2E** | End-to-End, prueba completa del flujo |
| **Flaky** | Test que falla intermitentemente |
| **Fixture** | Datos de prueba predefinidos |
| **Framework** | conjunto de herramientas y reglas |
| **Hook** | Código que se ejecuta antes/después de tests |
| **Implicit Wait** | Espera automática del WebDriver |
| **Integration Test** | Prueba que verifica interacción entre componentes |
| **JUnit** | Framework de testing para Java |
| **Locator** | Estrategia para encontrar elementos UI |
| **Mock** | Objeto falso que simula comportamiento |
| **Page Object** | Patrón que encapsula página web |
| **Parallel** | Ejecución simultánea de tests |
| **Parameterized** | Test con múltiples datos de entrada |
| **pytest** | Framework de testing para Python |
| **Regression** | Verificar que cambios no rompen funcionalidad |
| **Retry** | Reintentar test fallido |
| **Selenium** | Framework de automatización web |
| **Smoke Test** | Prueba rápida de funcionalidad principal |
| **SUT** | System Under Test (sistema bajo prueba) |
| **TestNG** | Framework de testing para Java |
| **Unit Test** | Prueba de unidad aislada |
| **WebDriver** | API para automatización de navegadores |
