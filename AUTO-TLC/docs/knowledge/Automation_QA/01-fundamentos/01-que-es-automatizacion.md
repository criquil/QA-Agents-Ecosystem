# ¿Qué es Automatización de Testing?

> **Archivo:** 1 de 3 | **Sección:** Fundamentos | **Nivel:** Principiante

---

## Definición

La **automatización de testing** es el proceso de usar software para ejecutar tests de forma automática, verificando que una aplicación funciona correctamente según los requisitos definidos.

### Componentes Clave

| Componente | Descripción |
|------------|-------------|
| **Test Scripts** | Código que ejecuta las acciones |
| **Test Data** | Datos de entrada para los tests |
| **Test Environment** | Entorno donde se ejecutan |
| **Test Runner** | Motor que ejecuta los tests |
| **Reporting** | Generación de resultados |

---

## Beneficios

### 1. Velocidad

```
Manual: 1 hora para 100 tests
Automatizado: 5 minutos para 100 tests
```

### 2. Consistencia

```
Manual: Variación humana
Automatizado: Misma ejecución siempre
```

### 3. Reutilización

```
Manual: Re-ejecutar manualmente
Automatizado: Re-ejecutar con un comando
```

### 4. Cobertura

```
Manual: Limitado por tiempo
Automatizado: Amplia cobertura posible
```

### 5. Feedback Rápido

```
Manual: Al final del ciclo
Automatizado: En cada commit
```

---

## Tipos de Automatización

| Tipo | Ejemplo | Velocidad |
|------|---------|-----------|
| **Unit** | Jest, JUnit | Muy rápido |
| **Integration** | TestContainers | Rápido |
| **API** | REST Assured | Rápido |
| **E2E** | Selenium, Cypress | Lento |

---

## Resumen

- **Automatización** usa software para ejecutar tests
- **Beneficios:** Velocidad, consistencia, reutilización
- **Tipos:** Unit, Integration, API, E2E
- **Componentes:** Scripts, Data, Environment, Runner, Reporting
